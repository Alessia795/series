# PracticaEntorno26
AA entorno de desarrollo 2 semestre - series

La aplicación permite gestionar las series. 
Los diferentes usuarios pueden ser user o admin. 

Los user tan solo pueden visualizar el catalogo mientras que los admin pueden añadir nuevas series, nuevas temporadas o nuevos episodios a la serie.

Frontend : 
    HTML, 
    CSS, 
    JavaScript
Backend: 
    Node.js, 
    Express, 
    Knex, 
    SQlite

Para poder utilizar la aplicación es necesario instalar las dependencias.

Frontend: 
    cd frontend
    npm install
    npm start

Backend: 
    cd backend
    npm install
    npm start
